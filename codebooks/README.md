# Codebooks

The codebooks in this subdirectory outline each of the variables in the datasets present in the external (CBS-RA) and internal (LUMC) environment.
-	Codebook ELAN CBS: data available in the external environment of CBS-RA
-	Codebook ELAN-GP: GP-data available in the internal environment of LUMC
-	STIZON HA codebook 2023-09-28: codebook from Stizon

Of note, GP-data are available in both environments (for CBS-RA see ‘tabblad Huisartsen’ ), but there are some slight differences. See explanation on our website:
https://elan-dcc.github.io/researchers/environments_overview/
